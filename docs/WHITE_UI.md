# 화이트 차량 UI 조정

2026-11-15 사용자 요청: 휴게소·볼거리·일정을 홈과 같은 기준으로 정리하고, 화이트 테마와 한글 타이포그래피를 개선한다.

## 실제로 확인한 레퍼런스와 적용

| 레퍼런스 | 확인한 내용 | 이 앱에 적용한 판단 |
|---|---|---|
| [Apple CarPlay 캘린더](https://support.apple.com/ko-kr/guide/iphone/iphae27787a8/ios) | 공식 페이지의 캘린더 화면에서 시간·제목·장소가 일정 단위로 붙어 있다. 일정을 선택하면 길안내 등의 동작으로 연결한다. | 시간과 제목을 같은 행에 두고 목적지와 길안내를 바로 아래에 묶는다. PRD가 다음 일정 한 건을 제공하므로 빈 카드를 늘리거나 가짜 일정을 추가하지 않는다. |
| [Google 차량용 타이포그래피](https://developers.google.com/cars/design/automotive-os/design-system/typography) | 24dp 이상 핵심 본문, 4dp 단위 수직 정렬, 제한적인 Medium 사용, Roboto 미지원 언어에 Noto Sans 권장. 공식 예시 이미지도 확인했다. | Noto Sans KR 400/500을 유지하고 핵심 목록 본문 24/32, 제목 28/36·32/40으로 조정한다. 자간은 본문 -0.008em, 제목 -0.018em으로 통일한다. |
| [Google Map + Content](https://developer.android.com/design/ui/cars/guides/templates/map-content-template) | 목록과 지도 번호의 대응, 가까운 결과 우선, 명확한 주요 행동. | 사용자가 지정한 목록·지도 1:1을 유지한다. 장소명 아래에 거리·분류를 묶고 길안내 아이콘으로 행의 동작을 보여준다. |
| [토스의 8가지 라이팅 원칙](https://toss.tech/article/8-writing-principles-of-toss) | 불필요한 단어·빈 문장 제거, 다음 동작을 예상할 수 있는 문구. | 일정의 반복 질문과 홈으로 버튼을 제거하고 하단 탐색을 사용한다. 결과가 없는 화면도 설명과 복구 버튼을 한 묶음으로 배치한다. |

앞선 턴에 확인한 비공식 `toss-inspired-ux` 지침을 이어서 참고한다. 토스 전용 글꼴이나 컴포넌트를 포함하지 않는다. Woody UI 사전은 이번 조회에서 연결이 완료되지 않아 확인한 근거에 포함하지 않는다.

## 적용 값

- 배경 `#F3F5F7`, 카드 `#FFFFFF`, 본문 `#202630`, 보조 본문 `#626C79`, 구분선 `#E3E7ED`.
- 파랑은 길안내·주요 버튼·선택 상태에 사용한다. 장식용 색과 배지를 추가하지 않는다.
- 카드 모서리 20dp, 버튼 14dp, 기본 버튼 높이 64dp. 카드와 탭바의 외곽 테두리·그림자는 사용하지 않는다. 탭 선택 영역의 테두리도 제거하고 배경색으로 선택을 표시한다. 목록 행은 최소 152dp이며 큰 글씨와 여러 줄 이름에 맞춰 늘어난다.
- 본문 행간은 4dp 단위로 맞춘다. 제목은 약 1.25배, 본문은 약 1.33배. 불필요한 글꼴 상하 패딩을 제거한다.
- 지도와 목록의 너비는 각각 580dp. 모든 탭에서 헤더는 상단 24dp, 탭바는 하단 24dp에 고정한다. 탭바 높이는 기본 84dp다.
- 일정은 고정 헤더 바로 아래에 날짜와 카드를 위에서부터 배치한다. 헤더·날짜·카드의 왼쪽 기준선은 모두 48dp다. 헤더–날짜 간격은 24dp, 날짜–카드 간격은 16dp, 날짜·카드 폭은 헤더와 같은 1184dp이며 좌우 여백은 48dp다. 탭바 폭은 928dp다. 탭바는 하단 중앙에 고정한다. 남는 높이는 카드 아래에 두며 카드 내부를 늘리지 않는다. 헤더와 탭바는 일정 내용 길이나 오류 상태에 따라 이동하지 않는다.
- 일정 카드는 28dp 안쪽 여백을 사용한다. 라벨 세 개의 첫 기준선을 맞추고, 본문 세 개도 첫 기준선을 따로 맞춘다. 시작 시간은 144dp, 목적지는 내용 너비(최대 424dp), 길안내는 216×64dp다. 시간은 카드 안쪽 왼쪽, 버튼은 안쪽 오른쪽에 고정한다. 제목 열은 내용에 맞춰 112~240dp 안에서 정한다. 남는 폭을 세 간격에 균등 배분해 시간–제목–목적지–버튼을 배치한다. 정보 열 사이 최소 24dp, 목적지–버튼 최소 20dp에 여유 폭을 더하며 라벨 행–본문 행은 8dp 간격이다. 기본 시연 카드 높이는 약 164dp다. 위치 핀은 목적지 라벨과 중복되어 기본 크기 행에서 제거했다.
- 큰 글씨에서는 버튼을 제목·목적지 아래로 옮긴다. 내용이 가용 높이를 넘으면 날짜와 카드만 스크롤하고 헤더와 탭바는 고정된다. 기본 글씨 크기에서 시각 검증했으며 큰 글씨 동작은 별도 기기 검증이 필요하다.
- 홈의 휴게소·일정 제목과 거리는 32sp로 맞춘다. 두 카드의 제목–본문 간격은 8dp다. 휴게소·볼거리 목록은 28dp 좌우 여백을 공유하며 각 행에 길안내 텍스트와 아이콘을 둔다. 반복 안내 푸터는 제거한다.
- 새 설치 기본값은 화이트다. 사용자가 선택한 주간·야간 설정은 저장하며 경고도 현재 테마를 따른다.

## 확인 범위

실행 화면과 최종 빌드 검증 결과는 `IMPLEMENTATION.md`의 화이트 UI 검증에 기록한다. 화면에 보이는 시연 배지는 예시 장소·거리·일정을 실제 차량 데이터와 구분한다. 예시 지도는 기존 Figma 래스터 에셋이며 실제 위치 조회에는 OSM 타일 지도를 사용한다.

## 홈·휴게소·볼거리 정렬 보완

- 홈 운전 카드 내부 여백도 28dp로 맞추고 운전 요약·휴식 알림의 상단 라벨 높이를 통일한다. 운전 시간 숫자는 88sp, 단위는32sp이며 속도 라벨·값은 기준선을 맞춘다.
- 휴식 알림의 제목–값은8dp, 정보–진행률–버튼은16dp 간격이다. 휴게소 찾기와 하단 두 카드의 행동 문구는 오른쪽에 붙인다.
- 보조 본문은24sp로 맞추며 장소 목록의 헤더·건수와 장소명·길안내도 각각 기준선을 맞춘다. 제목–거리8dp, 목록·지도1:1, 하단 탭 위치와 스타일을 유지한다.
